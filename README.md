# WhisperGUI Downloads

Download [WhisperGUI-Setup.exe](https://github.com/bsinghrana/whisper-gui-downloads/releases/download/v0.3.0a6-online.1/WhisperGUI-Setup.exe) and double-click it.

Setup downloads the required components automatically, shows progress, creates shortcuts, and opens WhisperGUI. No Python, Conda, command-line work, administrator access, or GitHub account is required.

The first setup downloads about 3.6 GB and needs approximately 10 GB of free disk space. If the connection is interrupted, choose **Retry**; completed download progress is reused.

The `.part` files on the release page are managed by setup. Users do not need to download or combine them manually.

See the [current Windows release](https://github.com/bsinghrana/whisper-gui-downloads/releases/tag/v0.3.0a6-online.1).
